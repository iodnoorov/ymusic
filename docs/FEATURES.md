# Возможности ymusic

Полное описание того, что умеет `ymusic`: экраны, окна, горячие клавиши, настройки и запуск из командной строки.
Установка и вход — в [README](../README.md).

> Для полных треков нужна подписка **Яндекс Плюс**, без неё API отдаёт только 30-секундные фрагменты.

## Экран программы

- **Шапка** — вкладки (`1`…`5`), логин аккаунта и отметка «Плюс». В узком окне у неактивных вкладок остаются только иконки.
- **Сейчас играет** — обложка, название, исполнители, альбом, откуда играет трек (волна, плейлист, альбом…)
  и есть ли он в «Мне нравится». Если ничего не играет — подсказки `w` и `2`.
- **Основная область** — содержимое текущей вкладки.
- **Плеер** — кнопки, название и исполнитель, эквалайзер (если включён), громкость и полоса прогресса со временем.
- **Нижняя строка** — подсказки по клавишам для текущего экрана или окна. Сообщения программы
  («Добавлено в «Мне нравится»», ошибки сети…) на несколько секунд показываются вместо подсказок, ошибки — красным.

Играющий трек в списках отмечен анимацией эквалайзера (на паузе — значком паузы, при загрузке — спиннером).
Недоступные треки показаны серым и при воспроизведении пропускаются.

Горячие клавиши работают и на **русской раскладке**: `д` = `l`, `т` = `n` и так далее. В полях ввода
(поиск, ссылка, название плейлиста) текст вводится как есть.

## Воспроизведение

| Клавиша       | Действие |
|---------------|----------|
| `Space` / `p` | пауза / продолжить |
| `n`           | следующий трек |
| `b`           | предыдущий трек; если текущий играет дольше 5 секунд или он первый — к его началу |
| `←` / `→`     | перемотка на 10 секунд |
| `+` / `-`     | громкость с шагом 5 % (до 130 %) |
| `m`           | без звука / вернуть звук |

- Звук идёт через **mpv**. Если установлен [mpv-mpris](https://github.com/hoyon/mpv-mpris), работают
  медиаклавиши и виджеты плеера в окружении рабочего стола.
- Следующий трек загружается заранее, поэтому переход между треками идёт без паузы.
- Когда очередь заканчивается, воспроизведение останавливается с сообщением «Очередь закончилась».
  Волна не заканчивается: новые треки подгружаются автоматически.
- С настройкой **«Доигрывать трек»** новый список (плейлист, «Мне нравится», поиск, альбом, исполнитель,
  ссылка, волна) не обрывает играющий трек. Очередь сразу заменяется новым списком, а текущий трек остаётся в ней
  первым и доигрывает, после чего начинается новый список. `n` переходит к нему сразу. Если трек на паузе
  или ничего не играет, новый список начинается сразу. Выбранный следом ещё один список заменяет ожидающий.
- Громкость, качество звука, эквалайзер и плавные переходы запоминаются между запусками.

## Вкладки

Переключение: `1`…`5`, `Tab` / `Shift+Tab`. Перемещение по спискам: `j`/`k` или `↑`/`↓`,
`PageUp`/`PageDown` — на 10 строк, `g`/`G` или `Home`/`End` — в начало / в конец. `Enter` — играть выбранное.

### 1 · Волна

Текущая очередь: волна, плейлист, альбом, лайки, результаты поиска — всё, что сейчас играет.

- Пока ничего не играет, здесь краткая памятка: `w` — Моя волна, `2` — станции, `3` — лайки, `5` — плейлисты,
  `/` — поиск, `?` — все клавиши.
- В заголовке — название источника; пока волна подгружает следующие треки, рядом крутится спиннер.
- Список сохраняет историю: уже прослушанные треки остаются выше текущего, к любому можно вернуться через `Enter`.
- `w` в любом месте программы запускает **Мою волну**.

### 2 · Станции

Волны, сгруппированные по разделам:

- **Моя волна** и её варианты, как в приложении: Любимое, Незнакомое, Популярное (характер)
  и Бодрое, Весёлое, Спокойное, Грустное (настроение);
- **жанры** — рок, метал, русский рок, альтернатива, инди, панк, поп, электроника, рэп, джаз, классика, саундтреки и другие;
- **настроения**, **занятия** (спорт, бег, работа, сон…) и **эпохи**.

Список станций подгружается из вашего аккаунта; пока он загружается, показан встроенный.
`Enter` — запустить станцию. Заголовки разделов при перемещении пропускаются.

Волна учитывает обратную связь: программа отправляет Яндексу события старта, пропуска и дослушивания трека,
лайки и дизлайки, поэтому рекомендации подстраиваются прямо во время прослушивания.

### 3 · Мне нравится

Все лайкнутые треки, в заголовке — их количество. Лайкнутые книги и подкасты сюда не попадают — только музыка.

- `Enter` — играть с выбранного трека по порядку;
- `s` — перемешать весь список и играть.

### 4 · Поиск

Поиск треков по названию и исполнителю.

- `/` из любой вкладки (или `i` на этой вкладке) — начать ввод; `Enter` — искать, `Esc` — выйти из ввода,
  `Ctrl+U` — очистить строку.
- Найденное подгружается страницами по мере прокрутки; заголовок показывает, сколько загружено из найденного
  («Результаты · 100 из 1234»). API сайта не сообщает, сколько всего найдено, поэтому с ним заголовок показывает
  «Результаты · 100+», пока не загружена последняя страница.
- `Enter` — играть с выбранного трека, `s` — вперемешку. Очередь, запущенная из поиска, сама пополняется
  следующими страницами результатов.
- Новый поиск не трогает то, что уже играет: старая очередь доигрывает, но больше не пополняется.

### 5 · Плейлисты

Ваши плейлисты, включая плейлист загруженных треков.
Играющий плейлист отмечен анимацией.

В списке плейлистов:

| Клавиша | Действие |
|---------|----------|
| `Enter` | открыть плейлист |
| `s`     | играть вперемешку |
| `E`     | переименовать (только свои) |
| `x`     | удалить (только свои, с подтверждением) |

В открытом плейлисте:

| Клавиша         | Действие |
|-----------------|----------|
| `Enter`         | играть с выбранного трека |
| `s`             | играть вперемешку |
| `x`             | убрать трек из плейлиста (с подтверждением) |
| `a`             | добавить трек в другой плейлист |
| `E`             | переименовать плейлист |
| `Esc` / `Backspace` | вернуться к списку |

**Добавление в плейлист** — `a` на любой вкладке: откроется список ваших плейлистов, выбор `↑`/`↓`, `Enter` — добавить.
Добавляется выбранный в списке трек, а если ничего не выбрано — текущий.

**Переименование** — окно с текущим названием: правка с клавиатуры, `Ctrl+U` — очистить, `Enter` — сохранить, `Esc` — отмена.

## История прослушиваний

Программа сообщает Яндекс Музыке, что и как слушается, — так же, как сайт: в начале трека, после 30 секунд
прослушивания, на паузе, в конце трека (дослушан, пропущен, `b` — назад, дизлайк, выбран другой трек или список)
и при выходе. В отчёте — откуда запущен трек (волна, «Мне нравится», плейлист, альбом, исполнитель, поиск) и сколько
секунд он на самом деле играл (перемотка не засчитывается). Это работает в обоих режимах API. Треки, прослушанные хотя
бы примерно наполовину, появляются в «Истории» Яндекс Музыки; короткие прослушивания сервер тоже принимает,
но в «Историю» не выводит.

## Лайки и дизлайки

| Клавиша | Действие |
|---------|----------|
| `l`     | лайк текущего трека; повторно — убрать лайк |
| `L`     | лайк трека, выбранного в списке |
| `d`     | дизлайк текущего трека: он пропускается и больше не попадётся в волне |

Лайки и дизлайки сохраняются в аккаунт Яндекс Музыки, а в волне ещё и отправляются ей как обратная связь.
Лайкнутые треки отмечены сердцем во всех списках, в карточке «Сейчас играет» и в плеере.
Если сервер не принял лайк, отметка откатывается и показывается ошибка.

## Быстрый запуск: исполнитель, альбом, волна по треку

Работают на любой вкладке с треком, выбранным в списке, а если ничего не выбрано — с текущим треком.

| Клавиша | Действие |
|---------|----------|
| `A`     | все треки главного исполнителя трека, самые популярные первыми (до 1000) |
| `e`     | альбом трека целиком, по порядку, со всеми дисками |
| `r`     | волна по треку — похожая музыка |

## Ссылки

| Клавиша | Действие |
|---------|----------|
| `y`     | скопировать в буфер обмена ссылку на выбранный (или текущий) трек |
| `Y`     | играть по ссылке: трек, альбом или плейлист |

**Копирование** работает через терминал (OSC 52 — в том числе по SSH) и через `wl-copy`, `xclip` или `xsel`, если они есть.

**Играть по ссылке** открывает окно ввода. Если в буфере обмена лежит ссылка на Яндекс Музыку, она подставится сама
(для этого нужен `wl-paste`, `xclip` или `xsel`); иначе ссылку можно вставить или набрать.
Ссылку можно и просто вставить в терминал (`Ctrl+Shift+V`, средняя кнопка мыши) на главном экране: окно откроется
само. Вставленный текст не срабатывает как горячие клавиши.
`Enter` — играть, `Ctrl+U` — очистить, `Esc` — отмена.

Поддерживаемые ссылки (домены `music.yandex.ru`, `.com`, `.by`, `.kz`, `.uz`):

- трек — `…/album/<id>/track/<id>` или `…/track/<id>`;
- альбом — `…/album/<id>`;
- плейлист — `…/users/<логин>/playlists/<номер>` или `…/playlists/<uuid>`.

Всё после `?` и `#` (метки `utm_*` и т. п.) отбрасывается. Ссылки на другие сайты не открываются вообще:
программа ничего не загружает и только сообщает «Это не ссылка на Яндекс Музыку».
Озвученные книги из Яндекс Книг тоже открываются по ссылке.

## Окно настроек

`o` — окно со всеми настройками. `↑`/`↓` — выбор строки, `←`/`→` — изменить значение
(по кругу), `Enter` — изменить или открыть, `Esc` (или `o`, `q`) — закрыть. Под списком — пояснение к выбранной строке.
Изменения применяются сразу и запоминаются.

| Настройка | Значения | Пояснение |
|-----------|----------|-----------|
| Качество звука | экономия трафика (≈64 кбит/с), обычное (≈192 кбит/с), лучшее | действует со следующего трека |
| Эквалайзер | Обычный, Больше баса, Вокал, Рок, Электроника, Мягкий, Колонки ноутбука | слышно сразу; выбранный пресет показан в плеере |
| Плавные переходы | выкл., 3, 5, 8, 12, 15 секунд | затухание в конце трека и нарастание в начале |
| Доигрывать трек | вкл. / выкл. | новый список начнётся после текущего трека, а не оборвёт его (см. «Воспроизведение») |
| Меньше ИИ-музыки | вкл. / выкл. | реже подмешивать в рекомендации треки, созданные нейросетями |
| API | мобильный / сайт | через какой API Яндекс Музыки работает программа (см. ниже) |
| Картинка | обложка, спектр, ничего | что показывать над треком в «Сейчас играет» (см. «Обложка и спектр») |
| Иконки | Nerd Font / простые символы | для терминалов без шрифта Nerd Font |
| О программе | — | `Enter` открывает окно «О программе» |
| Выйти из аккаунта | — | `Enter`, затем подтверждение: токен удаляется, программа закрывается |

- **Колонки ноутбука** — пресет «Колонки ноутбука» плеера music.yandex.ru, построенный так же, как на сайте:
  низкие поднимаются полочным фильтром на 60 Гц, высокие — полочным на 16 кГц, между ними пиковые фильтры с Q = 1.
  Тише всего около 1 кГц, сильнее всего подняты 12–16 кГц (до +11 дБ: соседние полосы складываются, как и на сайте).
- **Плавные переходы** — не настоящий кросс-фейд: треки не накладываются друг на друга, текущий плавно затихает,
  а следующий плавно нарастает. При ручном переключении (`n` / `b`) новый трек тоже нарастает с тишины.
  Подробности — в разделе README «Кросс-фейд (почти)».
- **Меньше ИИ-музыки** — настройка аккаунта Яндекс Музыки, та же, что в официальном приложении: изменение в одном месте
  видно в другом. Действует на следующие порции волны. Значение загружается при запуске и по `R`; если сервер
  не принял изменение, оно откатывается.
- **API** — запасной вариант на случай, если мобильный API (`api.music.yandex.net`) перестанет работать. В режиме
  «сайт» все запросы идут в API сайта music.yandex.ru (`api.music.yandex.ru`) так, как их отправляет сам сайт:
  его заголовки, его методы для лайков, дизлайков и настроек и его ключ подписи ссылок на звук. Настройки «Моей волны»
  (настроение, характер) сайт передаёт вместе с запуском волны, а не сохраняет в аккаунте. Возможности одинаковые.
  Отличия заметны в двух местах: в «Мне нравится» лайки показываются так, как их видит сайт (если трек в каталоге
  заменён другой версией, — сразу новая версия), а поиск не сообщает общего числа найденных треков.
  Переключение действует сразу: списки загружаются заново.

## Справка и «О программе»

- `?` или `F1` — справка: все горячие клавиши по разделам.
- «О программе» (из окна настроек) — версия и кликабельные ссылки на репозиторий и пакеты в AUR.

Оба окна закрываются любой клавишей; «О программе» возвращает в окно настроек.

## Обложка и спектр

Над треком в карточке «Сейчас играет» — обложка альбома, визуализатор спектра или ничего (`o` → «Картинка»).

Обложка текущего трека показывается:

- графикой — в терминалах с протоколами sixel, kitty или iTerm2 (foot, kitty, WezTerm, Ghostty, Konsole, iTerm2);
- цветными блоками — в остальных.

Пока обложка загружается (или если её нет), вместо неё рисуется цветной градиент, свой для каждого альбома.
Обложка подстраивается под размер окна. Если выбрана не обложка, обложки не скачиваются.

**Спектр** занимает то же место: 16 столбиков от 40 Гц до 16 кГц, низкие слева. Уровни считает сам mpv фильтрами
ffmpeg, поэтому столбики идут точно в такт звуку, а эквалайзер и плавные переходы в них видны. Столбики сразу
поднимаются и плавно опадают, на паузе гаснут. Анализ работает только в этом режиме: на компьютере он почти незаметен,
на Raspberry Pi 3 занимает около пятой части одного ядра.

## Командная строка

```bash
ymusic                       # открыть интерфейс
ymusic --wave                # сразу включить Мою волну (-w)
ymusic --station genre:metal # сразу включить станцию (-s): genre:rock, mood:calm, activity:workout, epoch:nineties…
ymusic --no-icons            # без иконок Nerd Font (только на этот запуск)
ymusic login                 # войти: меню «через браузер / по токену»
ymusic login --browser       # сразу через браузер (-b)
ymusic login --token <токен> # по готовому токену или URL с access_token= (-t)
ymusic whoami                # показать аккаунт и наличие Плюса
ymusic logout                # удалить сохранённый токен
ymusic --version
ymusic --help
```

Если запустить `ymusic` без входа, меню входа появится автоматически.

**Вход через браузер** открывает отдельное окно браузера с временным чистым профилем (основной профиль не затрагивается).
После входа токен подхватывается сам, а окно закрывается. Поддерживаются Firefox, Zen, LibreWolf, Floorp, Chromium,
Chrome, Brave, Vivaldi, Edge и Яндекс Браузер; по умолчанию берётся браузер по умолчанию.

## Конфиг и переменные окружения

Настройки хранятся в `~/.config/ymusic/config.json` (или `$XDG_CONFIG_HOME/ymusic/`), права `0600`:

| Поле        | Что хранит |
|-------------|------------|
| `token`     | OAuth-токен |
| `volume`    | громкость, 0–130 (по умолчанию 70) |
| `quality`   | качество звука: `lq`, `nq` или `lossless` |
| `eq`        | пресет эквалайзера: `flat`, `bass`, `vocal`, `rock`, `electronic`, `soft`, `laptop` |
| `crossfade` | плавные переходы в секундах, 0–15 (0 — выключено) |
| `art`       | что над треком: `cover` — обложка, `spectrum` — спектр, `none` — ничего (старое поле `covers: false` читается как `none`) |
| `finish_track` | `true` — новый список начинается после текущего трека, `false` — сразу |
| `web_api`   | `true` — API сайта music.yandex.ru, `false` — мобильный API (по умолчанию) |
| `icons`     | `true` — иконки Nerd Font, `false` — простые символы |

Программа сохраняет файл через пару секунд после изменения настроек и при выходе, поэтому править его вручную лучше
при закрытой программе. Если файл не удаётся прочитать (например, из-за опечатки), он переименовывается в
`config.json.bak`, а программа запускается с настройками по умолчанию.
«Меньше ИИ-музыки» хранится в аккаунте, а не в конфиге.

| Переменная         | Действие |
|--------------------|----------|
| `YMUSIC_TOKEN`     | токен на этот запуск (не сохраняется) |
| `YMUSIC_NO_ICONS`  | без иконок Nerd Font на этот запуск |
| `YMUSIC_BROWSER`   | браузер для входа, например `chromium` |
| `YMUSIC_MPV_ARGS`  | дополнительные параметры mpv через пробел, например `--ao=pulse --audio-device=…` |
| `YMUSIC_MPV_LOG`   | файл для лога mpv, если звука нет или mpv падает |
