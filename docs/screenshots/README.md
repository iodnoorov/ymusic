# Скриншоты

Положите сюда PNG-файлы с этими именами — они автоматически появятся в главном README:

| Файл            | Что снять                                     |
|-----------------|-----------------------------------------------|
| `mywave.png`      | вкладка «Моя волна» с играющим треком         |
| `stations.png`  | вкладка «Станции»                             |
| `search.png`    | вкладка «Поиск» без результатов                |
| `search2.png`    | вкладка «Поиск» с результатами                |
| `settings.png`     | Окно настроек                  |
| `help.png`     | Окно помощи                  |
| `playlists.png`     | Вкладка плейлисты                  |
